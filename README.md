# Travel_company - распределение задач в туристической фирме

## Описание проекта

Проект для автоматизации распределения обязанностей между сотрудниками туристической фирмы: менеджерами по продажам, гидами, водителями, агентами по бронированию и администраторами.

## Функционал

- Назначение туров и групп туристов сотрудникам с учётом их специализации.
- Учёт загруженности гидов и водителей по датам.
- Контроль распределения языковых групп (английский, немецкий, китайский и др.).
- Автоматическое оповещение о новых назначениях.
- Генерация отчётов по нагрузке и эффективности персонала.
- Формирование графиков работы на неделю / месяц.
